# NO MORE SIGNS 1.4.2

## 옵션 구성
옵션 → NO MORE SIGNS → 설정
1. 기본값으로 설정
2. 일반도로: 6개 숨기기 토글
3. 고속도로: 6개 숨기기 토글
4. 전체 활성화 / 전체 비활성화
5. 현재 실행 중인 모드 버전

ON = 숨김, OFF = 기본 표시입니다. 전체 버튼은 두 도로 종류의 12개 토글을 모두 변경하고 저장합니다. 기본값 복원도 두 도로 종류 전체에 적용되고 저장됩니다.

| 토글 | 일반도로 기본값 | 고속도로 기본값 |
|---|---|---|
| 표지판 숨기기 | ON | ON |
| 신호등 숨기기 | OFF | OFF |
| 가로등 숨기기 (광원 포함) | OFF | OFF |
| 기타 도로 프롭 숨기기 (소화전·전선함) | ON | ON |
| 속도제한 노면 표시 숨기기 | OFF | OFF |
| 차로 방향 화살표 숨기기 | OFF | OFF |

기존 여섯 설정은 일반도로 설정으로 유지합니다. 새 고속도로 설정은 위 기본값으로 시작합니다. 별도의 모드 설정 파일에 저장되며 도시 세이브에 전용 데이터를 추가하지 않습니다.

## 고속도로 판별
설치된 Game.dll의 Game.Prefabs.RoadData.m_Flags에서 Game.Prefabs.RoadFlags.UseHighwayRules를 확인합니다. 표시 이름, 번역, 제한속도, 차선 수로 추측하지 않습니다. 해당 플래그가 켜진 도로는 고속도로로, 꺼진 도로는 일반도로로 처리합니다. 커스텀 도로도 게임에 등록된 이 속성을 따릅니다.

소품의 Owner 관계를 따라 도로를 찾습니다. 도로 구간에 속하면 그 구간의 종류를 적용합니다. 교차로에 직접 속한 공용 소품은 연결된 도로들의 종류를 확인합니다. 일반도로와 고속도로가 섞인 교차로는 양쪽의 해당 숨기기가 모두 ON일 때만 공용 소품을 숨깁니다. 도로가 아닌 소유자, 건물에 속한 물체, 독립 배치 물체는 제외합니다.

## 언어
영어(en-US), 한국어(ko-KR), 일본어(ja-JP), 중국어 간체(zh-HANS), 중국어 번체(zh-HANT), 스페인어(es-ES)를 지원합니다. 게임 언어에 따라 옵션의 그룹명, 토글, 버튼, 설명이 바뀝니다. 고유 제품명 NO MORE SIGNS는 유지합니다.

## 렌더링과 저장
- 소품/데칼: 임시 PreCullingData의 표시 비트만 조정합니다. 토글 변경 시 게임 기본 BatchesUpdated로 렌더링 갱신을 요청합니다.
- 가로등: 해당 도로 종류의 가로등 숨기기가 ON이면 모델과 광원을 함께 숨깁니다. LightCullingSystem 앞에서 연결 광원의 임시 밝기를 0으로 하고 처리 직후 원래 밝기를 복원합니다.
- 도로/물체 삭제, 프리팹 생성 후보 수정, 차선 연결, 제한속도, 신호 규칙, 가로등 TurnedOff 상태는 변경하지 않습니다.
- 광원 및 표시 필터는 도시 저장 컴포넌트가 아닌 실행 중 렌더링 데이터에 적용합니다. 모드 설정의 저장과 도시 세이브는 별개입니다.

## 대상
표지판은 TrafficSignData, 신호등은 TrafficLightData, 가로등은 StreetLightData와 부속 모델로 분류합니다. 기타 프롭은 모델/유틸리티 정보 및 Hydrant/Electrical Box 이름으로 식별합니다. 노면 데칼은 MeshFlags.Decal을 확인한 뒤 SpeedLimit 종류 또는 LaneDirectionData로 구분합니다. 가로수, 교량/교각 구조물, 횡단보도/차선 등 나머지 데칼은 제외합니다.

복합 모델이나 커스텀 프롭의 분류에는 누락이 있을 수 있습니다. 모든 DLC/커스텀 도로 조합의 시각 검증을 완료한 것은 아닙니다.

## 인게임 확인
게임을 재실행하고 일반도로/고속도로에 각각 설정을 달리 적용해 확인합니다. 특히 고속도로 가로등만 숨길 때 일반도로 가로등과 광원이 유지되는지, 혼합 교차로의 공용 소품이 양쪽 ON일 때만 숨겨지는지 확인하세요. 전체 버튼과 기본값 버튼, 언어 변경도 확인합니다. 실제 저장 후 재로딩/모드 제거 복원 및 대도시 성능은 별도 실증 검증 대상입니다.
